Drop photos and stills here (jpg, png, webp, avif, gif). They show up in the Frames section on the next deploy.

Name files `2026-golden-hour.jpg` to get the title "Golden hour" and the year 2026.
To link a frame to its Instagram or X post, add a `captions.json`:

    { "2026-golden-hour.jpg": { "href": "https://instagram.com/p/..." } }
